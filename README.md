# Seminario de actualización

Repositorio de actividades del seminario. Desde la Clase 2, cada actividad
tiene una carpeta y una guía para reproducirla; el código y las dependencias
se incluyen según lo que requiere cada clase.

## Clases

- [Clase 2: preparación del entorno y primer proyecto](./Clase_2/README.md)
- [Clase 3](./Clase_3/README.md)
- [Clase 4: Gradio Blocks](./Clase_4/README.md)
- [Clase 5: publicación y documentación](./Clase_5/README.md)

La carpeta de Clase 3 está preparada, pero todavía no tiene archivos de la
actividad.

## Cómo trabajar con las actividades

Abrí la carpeta de la clase que quieras ejecutar y seguí los pasos de su
README. Cada clase puede requerir dependencias y comandos distintos; usá el
`requirements.txt` indicado en esa guía y seleccioná el entorno virtual de esa
carpeta cuando corresponda.

## Estado de la publicación de Clase 5

El código y la configuración para Render y Streamlit están en
[`Clase_5/`](./Clase_5/README.md). Los enlaces públicos se agregan a esa guía
después de desplegar las aplicaciones. El repositorio contiene una
configuración `render.yaml` para facilitar la publicación de Gradio.
